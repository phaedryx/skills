# Dimension prompt: dependency

What does this idea need in order to exist or act?

Possible values: **self-standing / loosely dependent / anchored / owned / parasitic.**

Substitution test: take away the thing it leans on — its owner, its parent, its host — and ask whether it still exists. Then give a self-standing version an anchor. When some instances survive the removal and others don't, what's being called one thing is two: a free-standing kind and an anchored kind, which usually want different names.

Distinct from scope (how far it reaches) and hierarchicalness (whether it nests): a thing can reach globally and still be unable to exist without one owner. Naming contrast: **Account vs. Membership**, **Document vs. Attachment**, **ServiceAccount vs. OrgCredential**.
