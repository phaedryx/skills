# Dimension prompt: granularity

Is this one item, a collection of items, a roll-up across items, or a summary of a roll-up?

Possible values: **one field / one row / one row per pair (join, membership) / collection / aggregate (owns children) / roll-up or summary / report.**

Substitution test: move one level up or down — what would the singular of this be, and what would the roll-up of it be called? If those names already exist nearby, this one has to sit between them without colliding. Plurals and collective nouns (`Roster`, `Ledger`, `Batch`, `Set`) are where this axis most often earns a name.
